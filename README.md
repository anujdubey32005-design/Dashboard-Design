# Task 4 – Sales Performance Dashboard

##  Project Overview
This project is part of my Data Analyst Internship – Task 4: Dashboard Design.

The objective of this project is to create an interactive Sales Performance Dashboard using **Microsoft Power BI**. The dashboard helps analyze sales performance, product categories, regional sales, and sales representative performance.

##  Objectives
- Analyze overall sales performance.
- Track important Key Performance Indicators (KPIs).
- Compare sales across different regions.
- Analyze product category performance.
- Evaluate sales representative performance.
- Create an interactive dashboard using slicers and filters.

##  Tools & Technologies
- Microsoft Power BI Desktop
- Microsoft Excel / CSV
- DAX (Data Analysis Expressions)
- GitHub

## Dataset Description
**Dataset:** `sales_data.csv`

The dataset contains 1,000 records and 14 columns.

Important columns include:
- Product_ID
- Sale_Date
- Sales_Rep
- Region
- Sales_Amount
- Quantity_Sold
- Product_Category
- Unit_Cost
- Unit_Price
- Customer_Type
- Discount
- Payment_Method
- Sales_Channel
- Region_and_Sales_Rep

## Key Performance Indicators (KPIs)
The dashboard includes:

1. Total Sales
2. Total Quantity Sold
3. Total Orders
4. Average Sales
5. Average Discount

## Dashboard Visualizations
The dashboard contains the following charts:

- **Monthly Sales Trend:** Analyzes sales over time.
- **Sales by Region:** Compares sales across different regions.
- **Sales by Product Category:** Shows category-wise sales performance.
- **Sales Representative Performance:** Compares sales generated by representatives.

## Interactive Filters
The dashboard includes slicers for:
- Region
- Product Category
- Sales Representative
- Customer Type
- Sales Channel

These filters allow users to explore sales data interactively.

##  Key Insights
- North region has the highest sales.
- Clothing is the highest-selling product category.
- Sales performance can be compared across different representatives.
- The dashboard helps identify regional and category-wise sales trends.

##  How to Run
1. Download or clone this repository.
2. Open Microsoft Power BI Desktop.
3. Open `Task4_Sales_Dashboard.pbix`.
4. If required, update the dataset source path to the downloaded `sales_data.csv`.
5. Explore the dashboard using the available slicers and filters.

##  Conclusion
This project demonstrates how Power BI can be used to transform raw sales data into meaningful visual insights. The interactive dashboard supports better understanding of sales performance and helps stakeholders make data-driven business decisions.
